# Gelateria d'Antan - Release Mobile-First 🍦

Una riprogettazione moderna, leggera ed estremamente veloce del sito di **Gelateria d'Antan** (`https://www.gelateriadantan.it/`), ottimizzata specificamente per l'utilizzo da dispositivi mobili (smartphone e tablet).

## Caratteristiche Principali 🚀

- **Single Page Application (SPA):** Navigazione fluida e istantanea senza ricaricamenti della pagina.
- **Interfaccia "App-Like":** Barra di navigazione inferiore fissa e comandi a portata di pollice, ideale per l'uso con una sola mano.
- **Orari Real-Time:** Un indicatore dinamico mostra se la gelateria è aperta o chiusa in tempo reale in base all'ora locale e segnala i dettagli della prossima apertura.
- **Design Premium:** Palette di colori caldi ispirata ai toni del cioccolato, della nocciola e del pistacchio.
- **Swipe Gestures:** Possibilità di scorrere tra le sezioni (Home, Gelateria, Servizi, Chi Siamo, Contatti) trascinando il dito sullo schermo.
- **Azioni Rapide:** Pulsanti float ad accesso rapido per avviare chiamate telefoniche o impostare il navigatore su Google Maps.

## Tecnologie Utilizzate 🛠️

- **HTML5** semantico per accessibilità e SEO.
- **CSS3** vanilla (variabili personalizzate, effetti glassmorphism, flexbox/grid layout).
- **Vanilla JavaScript** per la logica dell'applicazione (SPA, orari dinamici e gesti swipe).
- Zero framework o librerie esterne pesanti per garantire caricamenti inferiori a 100ms.

## Sviluppo Locale 💻

Per visualizzare il progetto localmente:
1. Clona questo repository.
2. Apri il file `index.html` direttamente nel tuo browser, oppure avvia un server locale leggero.
